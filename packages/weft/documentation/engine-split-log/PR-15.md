# PR 15 — Engine bulk operations extraction

## Scope

Extracts bulk workflow operations, purge behavior, retention purge scanning,
and purge storage cleanup helpers from `src/core/engine/index.ts` into
`src/core/engine/bulk-operations.ts`.

This PR keeps the `Engine` public method surface intact. Public bulk-operation
methods now delegate to module-level functions that receive `EngineInternals`
as their first argument. Private bulk-operation and purge helpers were removed
from the `Engine` class.

## Files added/changed

- `src/core/engine/bulk-operations.ts` — bulk cancel, signal, delete, tag,
  untag, purge, retention purge scanning, purge storage cleanup, and supporting
  retention helpers.
- `src/core/engine/index.ts` — imports the extracted helpers and retains thin
  public shim methods in the `Engine` class.
- `documentation/engine-split-log/PR-15.md` — records this extraction.
- `documentation/oxlint-disable-inventory.md` — moves the extracted oxlint
  disable inventory entries to their new file.

## Notes

- `deleteAll()` and purge paths pass the existing `Engine` waiter cleanup
  callback into the extracted module so private waiter cleanup behavior stays
  centralized in `Engine`.
- `#runRetentionSweep()` stays in `Engine` because it still reports cleanup
  errors through `#handleCleanupError()`, but now delegates purge work through
  `purgeInternal()`.
- `releaseChargedAgentOperations()` is exported from the internal module
  because terminal cleanup outside the bulk-operation path still needs the
  same reverse-index cleanup logic.
- `TERMINAL_CLEANUP_DELAY_MS` moved with purge cleanup and is imported by
  `index.ts` for the terminal cleanup timer path.
