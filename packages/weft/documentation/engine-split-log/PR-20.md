# PR 20 — Engine human review extraction

## Scope

Extracts human-review handling from `src/core/engine/index.ts` into
`src/core/engine/reviews.ts`.

This PR keeps the `Engine` public method surface intact. Public review methods
now delegate to module-level functions that receive `EngineInternals` as their
first argument, with callbacks for instance-only capabilities such as event
dispatch, workflow failure, operation result delivery, and terminal cleanup
tracking.

## Files added/changed

- `src/core/engine/reviews.ts` — pending review listing, review lookup, review
  submission, review decision resolution, escalation timer handling, webhook
  delivery, review cleanup, and wait-review operation processing.
- `src/core/engine/index.ts` — imports the extracted helpers and keeps thin
  `Engine` shims.
- `documentation/engine-split-log/PR-20.md` — records this extraction.

## Functions extracted

Public `Engine` methods moved to module-level functions:

- `listReviews`
- `getReview`
- `submitReview`

Private `Engine` methods moved to module-level functions:

- `#resolveReviewDecision`
- `#handleReviewEscalationTimer`
- `#sendReviewWebhook`
- `#cleanupReviews`
- `#processReviewOperation`

## Notes

- `reviews.ts` imports `EngineInternals` from `./internals.ts` and waiter
  tracking helpers from `./signals.ts`; it does not import from
  `src/core/engine/index.ts`.
- The review complexity suppressions moved with the extracted implementations
  and keep the existing `ID:core-engine-submit-review-complexity` and
  `ID:core-engine-process-review-operation-complexity` identifiers.
- Await ordering from the original review paths is preserved, including
  terminal cleanup tracking before review creation, event dispatch before
  webhook delivery, timer scheduling before waiter registration, and timer
  cancellation before feeding the operation result.
- `#processReviewOperation` and `#cleanupReviews` remain as `Engine` private
  shims because existing class methods still call them.
