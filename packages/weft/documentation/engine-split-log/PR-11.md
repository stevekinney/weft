# PR 11 — Engine storage I/O extraction

## Scope

Extracts storage I/O helpers from `src/core/engine/index.ts` into
`src/core/engine/storage-io.ts`.

This PR keeps the `Engine` private method surface intact. Each extracted method
now has a thin `#private` shim in `Engine` that passes `EngineInternals` to the
module-level helper, preserving existing internal call sites and call ordering.

## Files added/changed

- `src/core/engine/storage-io.ts` — workflow and schedule storage read/write
  helpers that operate on `EngineInternals`.
- `src/core/engine/index.ts` — imports the extracted helpers and delegates the
  seven private storage I/O methods.

## Functions extracted

- `loadWorkflowState`
- `loadWorkflowResult`
- `commitWorkflowStateOperations`
- `loadScheduleState`
- `requireScheduleState`
- `writeScheduleState`
- `loadWorkflowStartHeaders`

## Notes

- No public exports were added from `src/core/engine/index.ts`.
- No storage write ordering changed.
- No `Promise.all` calls were introduced.
- No `oxlint-disable-next-line` comments belonged to the extracted methods.
- `storage-io.ts` does not import from `src/core/engine/index.ts`.
