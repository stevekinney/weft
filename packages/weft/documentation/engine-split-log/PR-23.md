# PR 23 — Engine activity operation extraction

## Scope

Extracts activity operation execution from `src/core/engine/index.ts` into
`src/core/engine/operations-activity.ts`.

This PR keeps the private `Engine` method surface intact. Activity operation
helpers now run as module-level functions that receive `EngineInternals` first,
with callbacks for the private `Engine` capabilities that still live on the
class.

## Files added/changed

- `src/core/engine/operations-activity.ts` — activity function resolution,
  activity verification and compensation helpers, worker and inline activity
  invocation, activity execution, and activity operation processing.
- `src/core/engine/index.ts` — imports the extracted helpers, keeps thin
  `Engine` shims, and routes direct activity operation call sites through the
  extracted module with activity callbacks.
- `documentation/engine-split-log/PR-23.md` — records this extraction.

## Functions extracted

Private `Engine` methods moved to module-level functions:

- `#getActivityFunctionWithMetadata`
- `#resolveActivityFunction`
- `#buildActivityVerification`
- `#buildActivityCompensation`
- `#invokeWorkerActivity`
- `#invokeInlineActivity`
- `#executeActivity`
- `#executeActivityOperationResult`
- `#processActivityOperation`

## Notes

- `operations-activity.ts` imports `EngineInternals` from `./internals.ts` and
  does not import from `src/core/engine/index.ts`.
- `ActivityOperationCallbacks` carries the remaining instance-private
  capabilities needed by the extracted functions: `runOperationWithResult`,
  `getComposedActivityInterceptor`, and `getComposedWorkflowInterceptor`.
- The `ID:core-engine-execute-activity-complexity` suppression moved with the
  extracted `executeActivity` implementation.
- Replay determinism is preserved by keeping activity result execution,
  compensation registration, and verification registration in the original
  order. The workflow-interceptor generator iteration in activity execution is
  unchanged, and no sequential awaits were converted to `Promise.all`.
