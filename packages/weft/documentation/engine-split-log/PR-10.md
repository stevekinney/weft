# PR 10 — Engine pure helper extraction

## Scope

Extracts module-level pure helpers from `src/core/engine/index.ts` into sibling
engine modules. These helpers operate on plain values and do not take `this`,
`Engine`, or `EngineInternals`.

**No class declarations extracted.** PR 9 owns class declarations.
**No Engine class methods extracted.** Later PRs own method movement.

## Files added/changed

- `src/core/engine/validation.ts` — schedule/workflow decoding guards,
  schedule and retention normalization, and value-shape predicates.
- `src/core/engine/state-utilities.ts` — timeline summaries, checkpoint
  sanitizers, pagination/filtering helpers, encoded comparison helpers, feed
  key helpers, header persistence helpers, and schedule state utilities.
- `src/core/engine/index.ts` — imports the extracted helpers and retains the
  Engine class, class declarations, handle helpers, storage resolution, and
  engine factory helpers.
