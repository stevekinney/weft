# PR 27: Stream Operation Extraction

## Scope

- Moved stream operation handling from `src/core/engine/index.ts` to `src/core/engine/operations-stream.ts`.
- Kept `Engine.getStreamChunks()` as a public method and delegated its implementation to `getStreamChunksFromInternals()`.
- Added `StreamOperationCallbacks` so the extracted module can call the existing operation-result runner and shared cleanup-error handler without importing the Engine class.

## Behavior Preserved

- `ctx.stream()` still writes chunks sequentially, persists stream metadata after all chunks are written, and cleans up partially written chunks if generation fails.
- Token stream feed notifications still fire only for the `tokens` stream key after each committed chunk write.
- Stream heartbeats still update the active workflow heartbeat details through `EngineInternals`.
- Public API surface is unchanged; no barrel exports were added.
