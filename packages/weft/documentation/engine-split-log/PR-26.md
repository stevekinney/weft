# PR 26 — Engine data operation extraction

## Scope

Extracts data operation handling from `src/core/engine/index.ts` into
`src/core/engine/operations-data.ts`.

This PR follows the existing engine split pattern: extracted helpers run as
module-level functions that receive `EngineInternals` first, with a callbacks
bundle for private `Engine` capabilities that remain on the class.

## Files added/changed

- `src/core/engine/operations-data.ts` — memo, offload, load, and archive
  operation processing.
- `src/core/engine/index.ts` — imports the extracted helpers, routes data
  operations through `operations-data.ts`, and removes the extracted private
  `Engine` methods.
- `documentation/engine-split-log/PR-26.md` — records this extraction.

## Functions extracted

Private `Engine` methods moved to module-level functions:

- `#processMemoOperation`
- `#processOffloadOperation`
- `#processLoadOperation`
- `#processArchiveOperation`

## Notes

- `#runOperationWithResult` remains on `Engine` because it owns result
  wrapping, workflow continuation, and failure routing for all operation kinds.
- `operations-data.ts` imports `EngineInternals` from `./internals.ts` and does
  not import from `src/core/engine/index.ts`.
- `DataOperationCallbacks` carries the remaining instance-private capability
  needed by the extracted functions: operation result wrapping.
- Replay determinism is preserved by keeping the original await ordering for
  memo execution, offload encoding and storage, load validation and decoding,
  and archive persistence.
- Dead private `Engine` shims are deleted rather than retained through
  `void this.#method` references.
