# PR 28: Agent Operation Extraction

## Scope

- Moved agent and speculation operation handling from `src/core/engine/index.ts` to `src/core/engine/operations-agent.ts`.
- Added `AgentOperationCallbacks` so the extracted module can call the existing operation-result runner, sub-operation executor, terminal-cleanup tracker, event forwarding, and workflow interceptor composition without importing the Engine class.
- Updated embedded agent sub-operations in `#executeSubOperation()` to reuse the extracted budget tracker, budget policy, namespace, and cost-recording helpers.

## Behavior Preserved

- `ctx.agent()` still unwraps the agent loop result to the final content string, records context cost, exposes token and agent observability accessors, and persists organization budget cost idempotently.
- `ctx.speculate()` still creates a speculative child context, drives yielded operations through the existing sub-operation path, drains verifications before commit, and rolls back on failure.
- Agent budget warning and exceeded events still dispatch on the engine and forward to workflow handles for both standalone and embedded agent operations.
- Public API surface is unchanged; no barrel exports were added.
