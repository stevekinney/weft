# PR 12 — Engine checkpoint I/O extraction

## Scope

Extracts checkpoint-related I/O helpers from `src/core/engine/index.ts` into
`src/core/engine/checkpoint-io.ts`.

This PR keeps the `Engine` public and private method surface intact. The
public methods and private checkpoint helpers now delegate to module-level
functions that receive `EngineInternals` as their first argument.

## Files added/changed

- `src/core/engine/checkpoint-io.ts` — checkpoint history, replay, timeline,
  event history, checkpoint persistence, checkpoint pruning, and development
  checkpoint validation helpers.
- `src/core/engine/index.ts` — imports the extracted helpers and retains thin
  shim methods in the `Engine` class.

## Functions extracted

- `getEvents`
- `listCheckpoints`
- `getCheckpointAt`
- `getTimeline`
- `replayTo`
- `persistCheckpoint`
- `pruneCheckpointHistory`
- `validateDevelopmentCheckpoint`

## Notes

- `checkpoint-io.ts` does not import from `src/core/engine/index.ts`.
- Private `Engine` method calls needed by `persistCheckpoint` are passed as
  callbacks from the shim instead of bypassing TypeScript private access.
- Checkpoint persistence preserves the original sequential ordering: the
  storage batch commit resolves before feed notifications, pruning, and
  attribute-change dispatch.
- The `core-engine-persist-checkpoint-complexity` oxlint disable moved with
  the extracted `persistCheckpoint` function.
- No public exports were added from `src/core/engine/index.ts`.
